# Analyse-de-ventes-pour-un-e-commerce
Analyse de ventes pour un e-commerce
Description
Ce projet simule le rôle de Data Analyst chez Le Grand Marché, une entreprise de grande distribution. L’objectif est de préparer et analyser des rapports de données de ventes afin d’optimiser les actions marketing et d’appuyer la prise de décision.

## Objectifs
Analyser les ventes du mois précédent pour identifier les tendances clés.
Produire un rapport clair et accessible à divers publics, en s’appuyant sur des graphiques et du storytelling.
Appliquer des bonnes pratiques d’accessibilité dans la présentation des données.
Fournir des recommandations stratégiques basées sur l’analyse.

## Instructions pour reproduire l’analyse
Télécharger les fichiers de données et rapports disponibles dans le dossier /data du dépôt.
Ouvrir les fichiers Excel contenant les données client et ventes.
Suivre les onglets et formules préconfigurées pour explorer les KPI et générer les graphiques.
Consulter le rapport mensuel au format PDF pour comprendre le storytelling et les recommandations.
Pour toute modification, s’assurer de respecter les formules afin de maintenir l'intégrité des données.

## Outils utilisés
Microsoft Excel (version 365) pour l’analyse des données et la création des graphiques.
PowerPoint pour la préparation de la présentation finale (facultatif).
Respect des règles d’accessibilité dans les couleurs et formats choisis.

## Résultats techniques
Rapport mensuel présenté en PDF, illustré par des graphiques clairs et pertinents.
Fichier Excel dynamique avec calculs automatiques des indicateurs clés.
Analyse des clients affiliés complétée avec visualisations adaptées.
Recommandations stratégiques justifiées par les données, destinées à améliorer les performances marketing.
